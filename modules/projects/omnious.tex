\datedsubsection{Omnious \textbar\ Visual Debugging Platform \href{https://www.mehedi-hasan-maruf.me/projects/omnious}{\small\faExternalLink*}}{Nov 2025 -- Present}
\begin{itemize}
    \resitem{Building a debugger that parses a TypeScript or JavaScript codebase into a graph of files, functions, and classes, then animates runtime traces over it and shows where errors cluster.}
    \resitem{An AI assistant suggests root causes tied to specific graph nodes, using embeddings in pgvector and a locally run LLM (Ollama). Community detection groups the graph into architectural layers.}
    \resitem{A TypeScript Turborepo monorepo: Fastify 5 and tRPC v11 backend, Next.js 16 / React 19 frontend, and PostgreSQL 15 on Supabase (pgvector, ltree, pg\_trgm, row-level security).}
    \resitem{Ships a CLI indexer and Express and Next.js SDKs; runs in Docker Compose and deploys through GitHub Actions.}
\end{itemize}
